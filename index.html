صندوق الرسائل وطلبات المقايسة

كل استمارة يرسلها العميل من الموقع تظهر هنا فوراً مع حالة المتابعة وتفاصيل المقايسة.

1. الباقات والخدمات الأساسية وأسعارها

عدّل اسم أي خدمة، وصفها، سعرها بالجنيه أو الدولار، ومدة التنفيذ بالأسابيع (يسمّع فوراً في الموقع والحاسبة).

2. إضافات ومميزات حاسبة التكلفة (Add-ons)

تحكم في أسعار المميزات الإضافية داخل حاسبة تكلفة المشروع أو أضف مميزات جديدة.

3. معاملات أولوية التنفيذ والتصميم

نسبة الضرب في السعر الأساسي (مثلاً 1.0 = السعر العادي، 1.2 = زيادة 20%).

إدارة المشاريع وسابقة الأعمال (Portfolio)

أضف مشاريع جديدة أو عدّل تفاصيل وتقنيات المشاريع المعروضة في الموقع.

نصوص الواجهة الرئيسية وبيانات التواصل

أي تعديل هنا يتحدث في الصفحة الرئيسية والفوتر وقسم التواصل فوراً.

مراحل البناء الهندسي للمشاريع (4 خطوات)

⚡ اتصال السيرفر الخلفي (Vercel Serverless + Supabase Env)

يتم قراءة رابط قاعدة البيانات DATABASE_URL ومفاتيح التشفير من Vercel Environment Variables على السيرفر مباشرة دون كشف أي مفاتيح في المتصفح.

متغيرات البيئة المطلوبة في لوحة تحكم Vercel (Settings → Environment Variables):
DATABASE_URL = postgresql://postgres:[PASS]@db.[REF].supabase.co:5432/postgres
ADMIN_PASSWORD_SALT = 9f86d081884c7d659a2feaa0c55ad015
ADMIN_PASSWORD_HASH = 245ec7eeb904700e7d59923520b9a067...
SESSION_SECRET = random-64-char-hmac-secret-key
عرض كود SQL لإنشاء الجداول وتفعيل سياسات الأمان (Row-Level Security) في Supabase SQL Editor 
-- 1. جدول استمارات وطلبات العملاء (submissions)
create table if not exists public.submissions (
  id text primary key,
  name text not null,
  phone text not null,
  email text,
  service text,
  status text default 'new',
  brief text not null,
  created_at timestamptz default now()
);

-- 2. جدول إعدادات الموقع والأسعار والمشاريع (site_config)
create table if not exists public.site_config (
  id int primary key default 1,
  payload jsonb not null,
  updated_at timestamptz default now()
);

-- 3. تفعيل الحماية على مستوى الصفوف (Row-Level Security)
alter table public.submissions enable row level security;
alter table public.site_config enable row level security;

-- السماح للزوار بإرسال استمارة طلب فقط (INSERT) ومنعهم تماماً من قراءة رسائل الآخرين
create policy "Allow public insert submissions" on public.submissions
  for insert to anon, authenticated with check (true);

-- السماح للأدمن المسجل فقط بقراءة وتحديث وحذف رسائل العملاء
create policy "Allow admin full access submissions" on public.submissions
  for all to authenticated using (true) with check (true);

-- السماح للزوار بقراءة الأسعار والمشاريع فقط، وحصر التعديل على الأدمن فقط
create policy "Allow public read site_config" on public.site_config
  for select to anon, authenticated using (true);

create policy "Allow admin write site_config" on public.site_config
  for all to authenticated using (true) with check (true);
